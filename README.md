# Stylish Toggle Scientific Calculator

A dual-mode, modern calculator built with **HTML5, CSS3, and Vanilla JavaScript**. Featuring a clean "Soft UI" aesthetic that matches the Premium Unit Converter project.

## ✨ Features
- **Dual Mode**: Toggle between a standard calculator and a scientific layout.
- **Scientific Functions**: Support for `sin`, `cos`, `tan`, `log`, `sqrt`, `PI`, and exponents.
- **Keyboard Support**: Full integration for numpad, operator keys, Backspace, and Enter.
- **Clean UI**: Premium look with gradients, rounded corners, and subtle hover effects.
- **Responsive**: Adapts to mobile and desktop screens.

## ⌨️ Shortcuts
- **Enter**: Calculate result (`=`)
- **Backspace**: Delete last character
- **Escape**: Clear all (`C`)
- **Number keys & Operators**: Standard input

## 🚀 Installation
1. Save the code as `calculator.html`.
2. Open it in any web browser.
